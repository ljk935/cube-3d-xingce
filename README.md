# 立体图推 · 立方体拼接助手

一个专门解决**行测/公考「立体图形推理」里“小立方体拼接”这类题**的免费小工具。
不用装软件、不用登录，打开网页就能用；所有计算都在你自己的浏览器里完成。

**在线使用：<https://ljk935.github.io/cube-3d-xingce/>**

---

## 它能解决哪几类题

| 题型 | 对应页面 |
|---|---|
| 数一数这个立体图形由多少个小方块组成（含看不见的块） | ① 堆叠数块 |
| 给了主视图 / 左视图 / 俯视图，问最少、最多是多少块 | ② 三视图互推 |
| 几块积木能不能拼成某个长方体 / 指定形状 | ③ 拼接拼合 |
| 这张展开图能不能折成正方体、哪两个面相对 | ④ 展开图折叠 |
| 大正方体表面涂色，三面 / 两面 / 一面 / 没涂色的各几个 | ⑤ 涂色计数 |

顶部五个标签随时切换，每个页面各自记着自己的内容，切来切去不会丢。

## ① 堆叠数块

**怎么用**：在底板的格子上点一下，就往上叠一块；右键（或按住 Shift 点）拿掉一块。

- **拖动**画布：旋转视角；**滚轮**：缩放；右上角「重置视角」或按 `R` 键复位
- 底板大小可选 **3×3 / 4×4 / 5×5**，每列最多叠 **4** 层
- 「示例·阶梯」和「示例·遮挡」可以直接载入两个经典图形

**看哪里**：

- **方块总数**：一共几块
- **最高层数**：最高那一列几层
- **六面全被遮挡**：六面都被别的方块挡住、完全看不见的块（这类题最容易漏数）
- **表面积（单位面）**：露在外面的单位正方形面数
- **三视图**：随你搭的形状实时变化；**俯视图格子里的数字就是这一列的高度**，用它数块最快

**联动**：点「用这组三视图求『最少 / 最多』→」会把当前三视图直接带到第②页。

> 小技巧：在俯视图里填数字（每格高度），再回第①页搭出来，就是考试里“俯视图标数”的做法。

## ② 三视图互推

**怎么用**：直接点格子把三视图画出来。

- 主视图：横排 = 第 1…N 列，高度从下往上
- 俯视图：上 = 后排，下 = 前排
- 左视图：横排 = 第 1…N 排
- **同一个高度点第二次＝降低一格**，所以点错了不用重来
- 网格可选 3×3 / 4×4 / 5×5，列高最高 4

**结果**：

- **最少方块数** 与 **最多方块数**（都是精确值，不是估的）
- 下面一行给出“最少”的算式：俯视图占用格数（每格至少 1 块）＋ 主视图要补的高度 ＋ 左视图要补的高度 － 两视图能共用的格子
- 若三个视图互相矛盾（比如主视图某列高 4，但左视图最高才 3），会直接判**无解**并指出是哪一条矛盾
- 右侧可以在「最少摆法 / 最多摆法」之间切换，3D 预览同样满足这组三视图，用来理解“为什么会有这么多可能”

**点「载入示例」**：高度 1 / 2 / 3 的阶梯 → 最少 16 块、最多 18 块。

## ③ 拼接拼合

**怎么用**：

1. 左边「目标空间」先定长宽高（宽 X / 深 Y / 高 Z，各 1~4），点「填满长方体」可得完整长方体，也可以逐格去掉做出缺口
2. 四个拼块 A / B / C / D，各自在 3×3×3 的空间里点出来（每块可自由造型）
3. 点「开始求解」

**结果**：能拼 → 每种拼块用不同颜色显示在目标里，一眼看出谁放哪；不能拼 → 直接说明原因（体积不符 / 无解）。

**规则**：每块可以用一次，可以任意旋转（24 种朝向），但**不能翻面、不能镜像**——和考场一致。

**点「载入示例」**：4 个 L 形三连块拼 3×2×2。

## ④ 展开图折叠

**怎么用**：在 7×7 的网格里点亮 **6 个边相连的格子**，组成一张展开图。

- 超过 6 个会提示，先取消一个
- 亮满 6 格后自动判断：**能不能折成正方体**
- 能折时，**相同颜色的两个格子就是相对面**，右侧同时列出三组相对面
- 点「查询两面关系」，再依次点两个格子，会直接告诉你这两个面折起来是**相对**还是**相邻**
- 「快速载入」里有十字形、1-4-1、2-3-1 三个正确例子和一个错误示例，可对照理解

> 结论参考：正方体展开图一共只有 **11 种**（旋转、翻转后相同的算同一种）。工具里任意点亮 6 格，是不是那 11 种，一试便知。

## ⑤ 涂色计数

**怎么用**：用 `−` `+` 调出棱长 n（1~12），立刻得到：

- 三面涂色：8 个（顶点）
- 两面涂色：12(n−2) 个（棱上，不含顶点）
- 一面涂色：6(n−2)² 个（每面内部）
- 零面涂色：(n−2)³ 个（内部）
- 总数校验（四个数相加应等于 n³）与表面积 6n²

## 结果是准的吗

- **最少 / 最多方块数**：最少是精确最优解（按“每层最少要几个代表格”的结论求解，并用穷举所有可能摆法交叉验证过；最多是每个俯视格取 `min(主视图高度, 左视图高度)` 求和）。例如 3×3 全满、三视图都是 3 层高，答案是**最少 15、最多 27**。
- **拼接**：精确覆盖搜索，说能拼就真能拼（会给出具体摆法）；说不能拼就是这四块确实拼不出来。
- **展开图**：按“沿纸面逐步卷起”的几何模型计算；穷举全部 216 种六格连通图形，能折的正好 11 种，与已知结论一致。

## 使用边界（先说清楚，省得你怀疑）

- 堆叠按“每列叠高”建模，**没有悬空、镂空**的结构（这类题基本不出现悬空块）
- 堆叠最高 4 层，底面 3~5 格
- 拼接：目标区域最多 4×4×4 且不超过 60 格；单块最大 3×3×3；一共 4 块
- 三视图网格 3~5，单列高度最高 4
- 没有存档功能，刷新页面内容会清空

## 常见问题

**Q：为什么“最少”不能是 12 块？**
因为每个俯视格至少 1 块，而且主视图每一列的最高值、左视图每一排的最高值都必须真的被某个格子撑起来；同一个格子可以把“这一列最高”和“这一排最高”两件事一起完成，所以最少数目介于两者之间。工具给出的算式就是这件事的展开。

**Q：我明明觉得能拼上，它却说不行？**
先检查三件事：体积（所有拼块格数之和 = 目标格数）、有没有用到镜像（比如左右手性的块）、有没有超出 3×3×3。

**Q：手机上为什么右边面板跑到下面了？**
窄屏下是上下布局，往上滑就能看到统计和三视图。

## 开发者信息

单文件实现，无任何依赖：一个 HTML 里包含全部样式与脚本，离线可用。

```text
src/core.js      纯算法（三视图 min/max、拼接精确覆盖、展开图折叠、表面积/涂色）
src/ui.js        Canvas 2D 正交投影渲染 + 五个页面交互
src/style.css    样式
template.html    页面骨架
build.mjs        把以上拼成单文件 index.html / 立体图推.html
test/core.test.js 算法测试（45 项，含穷举交叉验证）
```

改完源码后：`node build.mjs` 重新生成，`node test/core.test.js` 跑测试。
